= A2ML Conformance Corpus

// SPDX-License-Identifier: CC-BY-SA-4.0

Local positive and negative fixtures for the A2ML validator, indexed by
link:manifest.a2ml[manifest.a2ml].

== Layout

* `valid/` — fixtures that must validate with zero errors.
* `invalid/` — fixtures that must error under `INPUT_STRICT=true`.

== Rules exercised

Identity (`name` / `project` / `agent-id`), `version`, a license marker in the
first ten lines, and well-formed `[attestation]` / `[section]` blocks. Files
under `.machine_readable/` are identity-exempt but not license-exempt;
`*AI-MANIFEST*` files are identity- and version-exempt.

Negative fixtures are classified as: missing identity (error); and missing
version, missing license header, empty attestation, and malformed heading
(warnings that become errors under strict mode).

== Deed fixtures

The corpus covers both scanned extensions. The `.deed` fixtures in `valid/`
are one per ruled deed head (DEED-GRAMMAR-SPEC `<<document-forms>>`):
`estate-deed`, `repo-deed`, `praxis-deed` and `estate-atlas-deed`.

`ATLAS.deed` carries `:registry-version` and deliberately no `:canonical-name`:
per the spec, the head symbol itself satisfies the structural half of identity,
so the atlas form must pass on its head alone.

The two negative deeds are `deed-missing-head.deed` (no ruled head and no
identity keyword — error) and `deed-missing-version.deed` (no
`:schema-version` — warning, error under strict).

Run link:run-deed-tests.sh[run-deed-tests.sh] to exercise them behaviourally.
It asserts on the discovery COUNT, not just the exit code, because the defect
it guards produced exit 0 by scanning nothing at all.

== Authoring gotcha

A negative fixture's COMMENT must not contain the literal license token, or a
missing-license case will self-pass.

== Verify

[source,sh]
----
# positive: zero errors
INPUT_PATH=conformance/valid   INPUT_STRICT=true  <validate-deed.sh>
# negative: every case errors
INPUT_PATH=conformance/invalid INPUT_STRICT=true  <validate-deed.sh>
----
